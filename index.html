Arena١٠٠ نسخة تشتغل

لو رد Claude مش عاجبك، بدل ما تعيد السؤال شغّل /arena. بتعمل ١٠٠ نسخة تشتغل على نفس المهمة، كل واحدة بأسلوب تفكير مختلف، وبعدين بيتقابلوا اتنين اتنين ويقيّمهم حكم، والخاسر بيطلع، لحد ما يفضل أقوى رد.

  • بتشتغل جوه مجلد .arena/ ومبتلمسش ملفاتك.
  • الجولات: ١٠٠ ← ٥٠ ← ٢٥ ← ١٣ ← ٧ ← ٤ ← ٢ ← ١.
  • رجّعلك الحل الفايز والهجمات اللي كسبها.

التثبيت من Claude Code

git clone https://github.com/Jakeschincariol/arena-skill.git
cp -r arena-skill/skills/arena ~/.claude/skills/
أو ابعت رابط المصدر لـ Claude وقوله «ثبّت المهارة دي وتأكد إن /arena شغّال».

Task Observerبيشوف تصحيحاتك

مهارة بتراقب شغلك مع Claude: بتلاحظ تصحيحاتك وتفضيلاتك، وبتقترح عليك تحسينات للسكيلز اللي عندك، وبتكتشف الشغل المتكرر وتقترح تحوّله لسكيل جديد.

  • بتسجّل ملاحظات وتحوّلها لتحسينات في مراجعة دورية، وانت اللي بتوافق.
  • بتراقب نفسها كمان وبتحسّن طريقتها.

التثبيت (محتاج Node.js)

npx skills add rebelytics/one-skill-to-rule-them-all --skill task-observer
مهم: بعد التثبيت ضيف تعليمة التفعيل من ملف references/environments.md في الـ CLAUDE.md بتاعك، وإلا ما هتشتغلش في كل جلسة. وللتطبيقات (ويب وديسكتوب) ارفع ملف .skill من آخر إصدار من Settings ← Customize.

Claude-Memبتساعد Claude يفتكر

Claude بينسى كل حاجة أول ما الجلسة تخلص. الأداة دي بتسجّل اللي حصل في جلساتك وتفتحلك الجلسة الجاية بذاكرة من الجلسة اللي قبلها.

  • الذاكرة بتتخزّن على جهازك في ~/.claude-mem.
  • المزامنة السحابية اختيارية، وإحصائيات الاستخدام المجهولة شغّالة تلقائيًا ومتقفلة بأمر npx claude-mem telemetry disable.

التثبيت

npx claude-mem install
أو من جوه Claude Code بالأمرين دول واحد ورا التاني:
/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem
انتبه: المُثبّت بيطلب تسجيل دخول في المتصفح واختيار مزوّد للذاكرة (فيه فترة تجريبية بتطلب وسيلة دفع)، وتقدر تتخطاه بـ --provider.
المصدر على GitHub
Headroomتوكنز أقل

بتضغط اللي Claude بيقراه (نواتج الأدوات واللوجات والملفات وتاريخ المحادثة) قبل ما يوصله، فتوكنز أقل والإجابات نفسها. الضغط بيتم على جهازك ومفيش محتوى بيتبعت لأي مكان عشان يتضغط.

  • في وصفهم الرسمي: توفير ٢١–٥٧٪ من توكنز الإدخال في أربع سيناريوهات قياس، وأكتر من ٩٠٪ في مصفوفات JSON واللوجات المتكررة، وقليل في النصوص العادية.

التثبيت

uv tool install --python 3.13 "headroom-ai[all]"
headroom wrap claude
أو pip install "headroom-ai[all]". وللتأكد إنه شغّال: headroom doctor. ملحوظة: التثبيت الكامل بيحمّل مساحة كبيرة على القرص.

OmniRouteبوابة واحدة

بوابة واحدة على جهازك لأكتر من مزوّد. تطبيقاتك بتتصل بيها هي، ولو الـLimit الخاص بـ Claude خلص بتحوّل للمزوّد التاني تلقائيًا.

  • بتشتغل مع أدوات زي Claude Code وCursor وCline، وبتتحكم فيها من لوحة تحكم محلية.

التثبيت

npm install -g omniroute
راجع شروط استخدام كل مزوّد قبل ما تربط حساباتك، ومشاريع التوجيه بين المزوّدين ممكن تتعارض مع شروط بعضهم. وبتحتاج تضيف حسابات المزوّدين بنفسك.
